# Systematic/scoping review and meta-analysis

Inputs: research question, protocol status, eligibility scope, studies and available databases. Never report a planned review as completed.

1. Read both `evidence-systematic-review` and `scholar-systematic-review`; specify protocol, databases, complete search strings, deduplication, screening process and conflict resolution.
2. Use `evidence-data-extraction` for a traceable extraction form. Record actual screening counts and exclusion reasons. Use `evidence-study-designs-and-evidence-levels` and `evidence-study-appraisal` for design-appropriate appraisal.
3. Read `evidence-meta-analysis` before pooling. Establish compatible outcomes, effect scales, dependencies and model assumptions. Use `scholar-data-analysis-plan` for reproducible analysis and sensitivity plans. Without suitable data/software, provide a plan and state that no pooled estimate was computed.
4. Run selected software on authorized data, retaining code/environment, uncertainty, heterogeneity and sensitivity results. Do not fabricate effect sizes or PRISMA counts. Use scientific visuals/table QA for final figures.
5. Produce the review narrative with evidence-strength distinctions using `evidence-evidence-answer` and `scholar-evidence-synthesis`.

Outputs: protocol/search log, screening/exclusion records, extraction and appraisal tables, reproducible analysis if run, evidence synthesis and limitations. Gate: counts reconcile; estimates trace to study inputs; executed steps are distinct from planned steps.
