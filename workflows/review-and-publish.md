# Review and prepare publication

Inputs: actual manuscript, target venue or selection criteria, current author guidelines, reviewer comments and available evidence.

1. Use `scholar-journal-finder` and `scholar-source-evaluation` for venue fit, current requirements and credibility. Verify guidelines and do not fabricate acceptance likelihood, fees, indexing or policies.
2. Read `arms-paper-critic`, `arms-paper-grader` and `scholar-peer-review-critique`; check methods/evidence and make actionable findings with locations. Missing shared ARMS rubric means its exact scoring system is unavailable; label use of the supplied embedded rubric instead.
3. Use `scholar-submission-checklist`, `latex-journal-templates` and the compatibility venue compliance role for a concrete source-to-requirement checklist. Mark unverified guidelines.
4. For revision read `scholar-reviewer-response` and `arms-paper-fixer`; respond point-by-point with actual changes and justified disagreements. Never claim an analysis was run if it was only proposed.
5. Rebuild and recheck affected artifacts. Prepare submission materials; do not submit externally unless the user requested/authorized that action.

Outputs: review report, corrected manuscript if requested, response letter, submission package/checklist and unresolved evidence/requirements. Gate: every reviewer item has a documented disposition and evidence; actual submission status is explicit.
