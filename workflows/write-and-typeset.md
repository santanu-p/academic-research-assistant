# Write, edit and typeset

Inputs: author contributions, actual sources/data, target genre/venue, draft, writing constraints and requested output format.

1. Read `arms-write-manuscript` or `scholar-outline-builder`, `scholar-abstract-introduction` and `scholar-paper-sections` as appropriate. For a thesis add `scholar-thesis-dissertation`. Build claim/contribution and evidence ledgers before drafting.
2. Apply the two guardrails skills to align problem, mechanism and evidence; preserve definitions, chronology, ownership, uncertainty and limits.
3. Use `academic-humanizer`, `arms-house-style`, `scholar-academic-editing`, `scholar-word-reduction`, `scholar-academic-translation` or `scholar-paraphrase-summarize` for the requested edit. Read `scholar-originality-integrity`; never disguise source copying or promise detector evasion.
4. For LaTeX read `latex-latex-studio` and the specific document/journal/thesis/notation/bibliography specialists. Retain all editable source, bibliography and figure assets. Verify citations with evidence specialists and source locations.
5. Compile using an actual available backend, resolve diagnostics, render and inspect pages where required. The source instructions do not supply a compiler; report any unavailable build. Fix syntax/content/layout issues without changing evidence.

Outputs: requested substantive draft/revision, editable source and dependencies, built artifacts if requested/available, change log and verification limits. Gate: no invented results/references; source and final artifact agree; compile/render success is evidenced, not inferred. Role: `agents/manuscript-editor.md`.
