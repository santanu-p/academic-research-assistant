# Revise against evidence

Read the draft with the user's requested scope, source material, figures, results, and citation keys. Identify each substantive claim and the evidence the author associates with it. Separate directly supported findings, interpretations, background claims, and proposals; flag missing or inaccessible evidence.

Revise for clarity and coherence while keeping the scope, strength, and uncertainty of each claim aligned with its support. Preserve quantities, units, comparison conditions, limitations, and citation placement. When evidence does not justify the original wording, narrow the claim or mark it for author confirmation instead of supplying a fabricated citation or result. Distinguish incomplete source verification from a verified contradiction.

Check quotations and bibliographic identifiers against accessible originals when needed. For code or LaTeX documents preserve functional syntax, labels, references, and the requested edit boundary. If the user asks for tracked changes or a particular file format, use an available appropriate document tool; otherwise provide a clear revision and change notes.

Return the revised passage or artifact with material changes and unresolved claim-source mismatches. State which sources and calculations were actually checked; do not imply the full literature or underlying data were independently verified.
