# Literature Review


## Types
| Type | Purpose |
|---|---|
| Narrative | Broad overview of a topic |
| Thematic | Organized by themes or debates |
| Chronological | How thinking developed over time |
| Methodological | How the topic has been studied |
| Scoping | Maps the size and nature of the literature |
| Integrative | Combines different kinds of evidence |
| Systematic | Transparent, reproducible method (see systematic-review) |

## Steps
1. Define the question and scope (years, fields, study types).
2. Find and screen sources (see find-studies and search-strings).
3. Extract key points into a matrix: source against themes.
4. Build an outline around themes or debates, not paper by paper.
5. Write with synthesis: connect studies, compare them, and evaluate them.
6. End with gaps, limits and how the user's work fits.

## Synthesis phrases
"Several studies report... (A, 2021; B, 2023), whereas C (2022) found...", "This difference may reflect...", "Evidence is strongest for... but limited for...".

## Output format
An outline first for long reviews, then sections written in full with in-text citations and a reference list. Use only verified sources or sources the user provided.

## Rules
Write original text. Do not copy passages from papers; paraphrase and cite.
