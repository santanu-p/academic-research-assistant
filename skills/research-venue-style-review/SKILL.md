# Review research writing for a venue

Identify the target venue, manuscript type, supplied author instructions, editorial stage and authorized scope of change. Inspect the current document and its source before editing. Obtain current official venue requirements when available, distinguish mandatory rules from recommendations and separate them from the author's existing style choices. If instructions are inaccessible or ambiguous, label the assumption and avoid claiming compliance.

Build a checklist for the relevant items: structure, word limits and counting rules, figure and table requirements, references, terminology, units, disclosures and submission files. Apply a rule only where the venue and document type actually require it. Do not generalize a journal's preferences into universal scientific writing rules.

Edit for clear argument, coherent section flow and precise language while preserving data, equations, citation keys, technical definitions, uncertainty, legitimate hedging and authorship. Check that each substantive claim remains supported by its cited evidence. Flag unsupported novelty, causal language or missing information instead of strengthening or inventing claims. If a change would alter scientific meaning, present it for the author's decision.

Check changed text against the original, update cross-references if needed, and run an actual build and visual inspection when editing an artifact. Return editable changes with a concise change record, source and date for venue requirements checked, and unresolved compliance or evidence questions. A style review does not establish acceptance or scientific validity.
