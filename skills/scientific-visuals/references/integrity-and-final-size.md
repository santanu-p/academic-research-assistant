# Integrity and final-size inspection

Record where every plotted value came from. Preserve raw data and a reproducible transformation record. If values are digitized, simulated, normalized, fitted or averaged, say so. Distinguish a model prediction from a measurement and a proposed experiment from a completed result. Shared datasets, apparatus and baseline implementations need accurate attribution. These helpers add no evidence of novelty, causal effect, universal validity or ownership.

Every uncertainty display needs a definition: standard deviation, standard error, credible interval, confidence interval, range, or another stated construction. Include the sample or replication unit where relevant. An arbitrary demonstration width is not a statistical interval. Non-overlap or overlap of displayed intervals alone generally does not answer an inferential question; use the justified analysis for that question.

Decide physical width and height before tuning labels. Inspect the exported figure at that size and at the expected viewing distance. At minimum, inspect all tick labels, axis units, legends, numerical annotations, mathematical glyphs, interval endpoints and panel labels. Verify that category names align with the underlying arrays. Check that caps do not touch numeric labels and that legends do not cover observations. Confirm axes ranges and baseline choices support the intended comparison. Do not rely on color alone when shapes or direct labels can distinguish groups.

SVG inspection reports width, height, viewBox, inline/inherited font attributes, external references and embedded resources. It does not implement a browser's complete CSS cascade, transforms or text layout. Font information can be unavailable for path-converted text, stylesheets or relative lengths. External resources can break portability; inspect whether the intended asset is embedded. The tool reports references without fetching them.

Raster inspection uses Pillow to report pixel dimensions and DPI metadata when present. DPI metadata alone does not prove sufficient resolution: compare pixel dimensions with final physical dimensions. PDF inspection uses PyMuPDF, first importing `pymupdf`, then the historical `fitz` name. It inspects all pages, extracts available span sizes and font embedding information, and optionally renders all pages. Outlined, scanned or nonextractable text cannot be checked as live text. An absent backend yields `incomplete`, never a successful inspection.

Automated checks cannot establish scientific accuracy, data integrity, appropriate statistical methods, semantics, text overlap or visual balance. The Matplotlib canvas audit catches visible text beyond the canvas and small font objects. A file audit does not duplicate that geometry check. Human inspection of the final SVG/PDF/PNG remains necessary. Record unavailable checks separately from passing checks, and retain the rendering used for review when reproducibility matters.

The bundled examples deliberately use invented values. They produce comparison, reliability and observed-frontier illustrations in three formats, accompanied by a JSON manifest that identifies synthetic provenance and arbitrary uncertainty widths. They are examples of figure construction, not research results.
