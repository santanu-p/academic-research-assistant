# Database Guide


## By field
| Field | Best places to search |
|---|---|
| Multidisciplinary | Google Scholar, Semantic Scholar, OpenAlex, Scopus, Web of Science, CORE, BASE |
| Education | ERIC, British Education Index, Education Source |
| Psychology and behavior | PsycINFO, PsyArXiv |
| Business and management | Business Source, ABI/INFORM, SSRN |
| Economics | EconLit, NBER working papers, RePEc, SSRN |
| Law | HeinOnline, Westlaw, LexisNexis, SSRN |
| Engineering and computing | IEEE Xplore, ACM Digital Library, arXiv, dblp |
| Environment and earth sciences | GreenFILE, AGRIS, Web of Science |
| Humanities | JSTOR, Project MUSE, MLA International Bibliography |
| Social sciences | Sociological Abstracts, JSTOR, SAGE journals |
| Theses | ProQuest Dissertations, EThOS, OATD |
| Grey literature | Government and agency sites, OECD iLibrary, World Bank Open Knowledge, think-tank reports |
| Datasets | Google Dataset Search, Zenodo, Dryad, Figshare, ICPSR |

## Tips
- Use at least two databases for a serious review; each covers different journals.
- Many subscription databases are free through a university or public library.

## Output format
A short, ranked list of the best 4 to 8 sources for the user's topic, with why each fits.
