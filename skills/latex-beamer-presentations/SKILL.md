# Beamer presentations

Determine audience, purpose, available speaking time and existing theme before editing. Inspect the main file, assets, aspect ratio, engine and overlay conventions. Preserve scientific claims and source attribution; make clear when a proposed diagram or example is illustrative rather than experimental evidence.

Make each frame support a clear point and favor readable text, equations and figures at projected size. Divide dense material across frames instead of shrinking it indiscriminately. Use overlays only when their sequence aids the talk and verify that content intended for later steps is not accidentally visible earlier. Keep diagrams, fonts and color contrast consistent with the deck's established theme.

Preserve frame labels, links and presenter notes when changing order; be mindful that overlays can create multiple PDF pages per frame. Keep assets and source paths portable. If a timed talk is requested, estimate pacing from actual content and indicate that a rehearsal is needed to establish real delivery time.

Build the main Beamer document using its configured engine and inspect the log. Render every PDF page, including each overlay, and check text size, clipping, formula breaks, figure labels and progress indicators. Report build or inspection limitations and provide editable source and dependencies for a completed deck.
