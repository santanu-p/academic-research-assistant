# Research Proposal Background


## Structure
1. **Context:** why the topic matters, with a key statistic or fact (cited).
2. **What is known:** synthesis of the main evidence.
3. **What is not known:** the gap (see research-gaps).
4. **Why it matters:** the cost of the gap for theory, practice or policy.
5. **This study:** aims, research questions and how the study fills the gap.

## The funnel
Move from broad to specific: field, topic, problem, gap, your question.

## Tips
- Lead with evidence, not opinion.
- Use recent reviews to show the state of knowledge; cite primary studies for specific claims.
- Match the funder's or institution's priorities and word limits.
- Make aims specific and measurable.

## Output format
A full draft of the section with in-text citations and a reference list, or an outline plus key sources for the user to confirm.

## Rules
Use only verified sources or those the user provided. The user should check all claims before submission.
