# Find Studies


## Purpose
Deliver real sources the user can open and trust, never made-up references.

## Steps
1. Clarify the question and concepts (see research-question) if the request is vague.
2. Search with web search when it is available. Look first for systematic reviews and meta-analyses, then landmark and recent primary studies.
3. Verify every source: the title, authors, year and journal must match a real record. Prefer a DOI or an official publisher, database or repository page.
4. Screen for relevance and quality. Drop sources that do not answer the question.
5. Order results: reviews first, then strongest primary studies, then newer or emerging work.

## For each source give
- Full reference (authors, year, title, journal or publisher).
- Study type and sample (for example "meta-analysis of 42 studies" or "survey of 1,200 employees").
- The key finding in one or two sentences.
- A link or DOI you verified.

## If you cannot search or verify
Say so clearly. Do not list references from memory as if they were confirmed. Instead give the search strings, the best databases for the topic, and names of well-known review types or authors to look up, labeled "to verify".

## Rules
- Never fabricate a citation, DOI, page number or quote.
- Flag preprints as not yet peer reviewed.
- Flag retracted papers if you find a retraction notice.
