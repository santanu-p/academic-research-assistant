# Reusable research roles

These Markdown files are portable role instructions for the host assistant or authorized delegated agents. They are not registered custom Codex agent types or standalone MCP tools. The router and workflows link them; each role specifies inputs, procedure, output and completion gate.

Core roles: evidence-librarian, methodologist, manuscript-editor, reproducibility-reviewer.

Compatibility roles: failure-diagnoser, consistency-auditor, venue-compliance-gate. These are new integration adapters derived from output contracts embedded in the supplied ARMS pipeline. They do not claim to reproduce absent private source implementations or scoring rubrics. Record their use as a substitution.
