## Findings resolved during review

1. **P2 — Namespace rewriting changed ordinary research terminology.** The former unrestricted substitution in `build_tools/build_plugin.py` changed prose such as “meta-analysis” into “evidence-meta-analysis.” The builder now limits rewrites to identifier contexts, commands, paths, and explicit routing-table cells (`build_tools/build_plugin.py:143–162`). The rebuilt `skills/evidence-systematic-review/SKILL.md:55` again says “meta-analysis,” and `skills/evidence-meta-analysis/SKILL.md:63` again reads “Reading a meta-analysis critically.” Verified after rebuild. No source URL changes were found when comparing all 117 active source skills against their frozen originals.

2. **P2 — Malformed tool calls used the tool-execution error channel.** Unknown tools and non-object `tools/call.arguments` originally returned `result.isError=true`. The runtime now returns JSON-RPC `-32602` for these cases (`academic-research-assistant/server/assistant_server.py:176–180`), retaining tool-result errors for actual execution/input-value failures. An independent subprocess retest confirmed both corrections and successful subsequent `ping`. This follows the [MCP tools error distinction](https://modelcontextprotocol.io/specification/2025-11-25/server/tools#error-handling).

3. **P2 — Invalid MCP request IDs were accepted or echoed.** The runtime previously accepted null/fractional IDs and could echo arbitrary invalid IDs from malformed envelopes. It now accepts only string/integer request IDs, rejects booleans, and sanitizes malformed-envelope IDs (`academic-research-assistant/server/assistant_server.py:153–161`). An independent subprocess retest confirmed `-32600` for null, fractional and boolean IDs, followed by a successful valid request. The [MCP base protocol](https://modelcontextprotocol.io/specification/2025-11-25/basic#requests) requires string or integer IDs and prohibits null request IDs.

4. **P2 — The PDF-inspection build dependency was undocumented.** `build_tools/inspect_sources.py:118` imports `pypdf`, which was absent from the original setup requirements. The added `dev/requirements-dev.txt` explicitly includes PyYAML, jsonschema, Pillow and pypdf; `docs/BUILD.md:18–27` documents reconstruction and prerequisites. The development bundle now includes the authored integration template, build scripts, adapters, tests and saved official schemas. Confirmed statically; a clean reconstruction execution remains the root agent's final validation task.
